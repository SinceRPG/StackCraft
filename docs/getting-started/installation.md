# Installation

Follow these simple steps to install StackCraft on your server.

## Prerequisites

1. A **PaperMC** (or Folia) server running Minecraft version `1.21`.
2. Any soft-dependency plugins you wish to use (e.g., MMOItems, ItemsAdder, Nexo, etc.).

## Steps

1. **Download** the latest release of `StackCraft` from [GitHub Releases](https://github.com/VoChiDanh/StackCraft/releases).
2. **Move** the `StackCraft.jar` file into your server's `plugins/` directory.
3. **Restart** your server.
4. **Configuration**: A new `StackCraft` folder will be generated in your `plugins/` directory containing the `config.yml`.

> [!WARNING]
> Do not use `/reload` or plugin managers like PlugMan to load the plugin. Always restart your server to ensure a clean load, especially when interacting with custom item plugins.
